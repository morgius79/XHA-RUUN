"Chromophyll 570 nm — Khar'Vex-mor sha-vek. Xa-the ven-mor sha-el copper-red vokh-ven green." — Institute of Botany, +3 100 E.U.

17.5.2 Ecological Functions

  • O₂ balance: forests ~62% atm O₂ (phytoplankton 35%, other 3%)
  • C cycle: ~27.3 bln ru CO₂/y sequestered
  • H₂O cycle: ~55% continental precipitation from forest transpiration
  • T regulation: Vexar forest lowers local T 2.2–4.3°X
