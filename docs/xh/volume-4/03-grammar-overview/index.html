Thexar-IV: The-Sha-Ruun — Sha-El 03: Khal-sha Rass — Grammar: Overview

"The Xha'Ruun language is agglutinative. Each morpheme is a building block from which utterances are constructed. 14 cases, 4 tenses, 3 numbers, 4 types of evidentiality — precision that tolerates no ambiguity." — Academician of Grammar, Tor-Ven

Ruun-ak rass: → rhu [Thexar-I, Ruun 06, "The-Sha-Ruun"], → rhu [Thexar-IV, Sha-El 01–02] Volume: 25 sha-ruun Mor-ven: Agglutinative system of high precision. Each grammatical category expressed by a separate morpheme — eliminates ambiguity: case, number, tense, evidentiality marked explicitly. Word structure: stem + number + case + (evidentiality). SOV order. Morphemes segmentable.

3.1 Typological Characteristics

Parameter Value
Type Agglutinative, suffixal
Word order SOV (subject-object-verb)
Cases 14
Numbers 3 (singular, dual, plural)
Gender None
Evidentiality Mandatory (4 types)
Tense 3 + 1 (past, present, future + gnomic)

Agglutination = dominant mode of inflection: morphemes attached sequentially, without fusion. Absence of gender simplifies agreement; triple number reflects the three-sex biology of the speakers.

3.2 Word Structure

Stem-(root) + number_suffix + case_suffix + (evidentiality)

Example: xha'ruun-ak-sha-ven → "people-PL-ERG-DIR" = "the peoples (I see that they)"

Order of suffixes fixed: number → case → evidentiality. Morphemes segmentable: each carries one meaning, making the word transparent for analysis.

3.3 Case System

The 14 cases divided into groups (→ rhu [Thexar-IV, Sha-El 04, "14 Cases"]):

  • Grammatical: nominative, ergative, accusative, genitive
  • Spatial: locative, ablative, allative, prolative
  • Temporal: temporal, prolative of time
  • Other: instrumental, comitative, benefactive, translative

3.4 Evidentiality

Mandatory category — the speaker is obliged to indicate the source of information (→ rhu [Thexar-IV, Sha-El 06, "Evidentiality"]):

  • Direct (saw/heard)
  • Inferential (conclusion)
  • Reportative (from others' words)
  • Quotative (direct speech)

3.5 Syntax

SOV order supplemented by:

  • Agglutinative postpositions (case suffixes perform their role)
  • Free order within the clause with marked cases
  • Complex sentences through suffixal conjunctions and evidentiality
