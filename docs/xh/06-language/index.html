6.2 Writing System

6.2.1 Type

Syllabo-logographic: 124 syllabic sign + 48 logogram. Direction: right→left, top→bottom.

6.2.2 Syllabary

CV structure: 124 sign = 24 consonant × vowel + null-consonant vowel. Example: 𐤁𐤀 (ba), 𐤂𐤀 (ka), 𐤃𐤀 (qa).

6.2.3 Logogram

High-frequency root: 𐤑 (Xha'Ruun), 𐤕 (the-), 𐤊 (khar-), 𐤔 (sha-).

6.6 Evidentiality ven Culture

Obligatory evidentiality = cultural value: respect for knowledge source.

Evidential Social Function
Direct (-sha) Witness — high reliability
Indirect (-mor) Told — source attribution
Inferential (-zal) Suppose — intellectual honesty
Reportative (-thar) "They say" — distance from unreliable

Lie with -sha = gravest offense (testimony distortion). Lie with -thar = less serious (relaying).
