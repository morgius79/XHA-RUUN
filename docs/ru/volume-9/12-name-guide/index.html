Том IX: Словарь — Глава 12: Гид имён Xha'Ruun

«Имя — не ярлык. Имя — это судьба. Дать имя — значит определить путь.» — Из «Книги имён», обряд наречения

12.1 Структура имени

Xha'Ruun имена — двусоставные: [основа-1]-[основа-2]. Ударение на второй части.

Примеры:

  • Khar-Vexar — «Свет-Дающий»
  • Ven-Khal — «Истина-Жизнь»
  • Shan-En — «Пламя-Бытие»

12.2 Окончания по полу

Пол Окончание Пример
Мужской (♂) -en, -un Verksen, Torun
Женский (♀) -a, -ae Thexa, Rhuae
Нейтер (⚲) -in, -el Sharin, Vexel
