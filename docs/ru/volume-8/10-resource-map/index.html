Том VIII: Атлас — Глава 10: Карта ресурсов

«Théxar дала нам всё — металл, энергию, воду, землю. Наш долг — брать лишь столько, сколько можем вернуть.» — Кодекс Хранителей, +1 200 г. Э.Е.

Связанные разделы: → см. [Том I, Гл.19, «Природные ресурсы»], → см. [Том I, Гл.12, «Геологическая эволюция»], → см. [Том VIII, Гл.08, «Геологическая карта»], → см. [Том I, Гл.33, «Термоядерная энергетика»] Объём: 20 страниц

Введение

Повышенная металличность протопланетного облага Khar'Vex ([Fe/H] = +0.12) обеспечила Théxar уникальной минеральной базой. Эта глава картирует распределение ключевых ресурсов, детально описанных в → см. [Том I, Гл.19].

Итоги главы

  1. Торий — 10.9 млн ру (коэфф. обогащения 2.5), 52% на Kharak.
  2. Железо — 254.6 млрд ру (коэфф. 2.8), платина — 109.1 тыс. ру (коэфф. 2.2).
  3. Пахотные земли — 0.341 млн мо² (12% суши).
  4. Лесные ресурсы — 725.6 млн ша³/цикл, строгое регулирование.
  5. Орбитальная энергетика — 420 ГВт, потенциал +600 ГВт.
  6. 15% планеты — Зоны Тишины.
