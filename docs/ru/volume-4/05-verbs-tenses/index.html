Том IV: Язык — Глава 5: Глаголы и время

«Глагол — это двигатель предложения. Он несёт действие, время и источник информации. Без глагола нет высказывания.» — Грамматика Xha'Ruun, Академия

Связанные разделы: → см. [Том IV, Гл.03, «Грамматика: обзор»], → см. [Том IV, Гл.06, «Эвиденциальность»] Объём: 25 страниц

Введение

Глагольная система Xha'Ruun — агглютинативная, с богатой словоизменительной морфологией. Глагол несёт действие, время и — обязательно — источник информации (эвиденциальность). Эта глава описывает спряжение, систему времён и глагольное словообразование.

5.1 Спряжение

Глаголы Xha'Ruun спрягаются по:

  • Времени (4 типа);
  • Числу (3: единственное, двойственное, множественное);
  • Эвиденциальности (4 типа — обязательно).

Субъект не согласуется по лицу — лицо факультативно выражается местоименными клитиками. Эвиденциальность обязательна: говорящий обязан указать источник информации (→ см. [Том IV, Гл.06]).

5.2 Система времён

Время Суффикс Пример Перевод
Прошедшее -ak khal-ak сделал
Настоящее -en khal-en делает
Будущее -mor khal-mor сделает
Вневременное -el khal-el делает (всегда)

Вневременное время (-el) маркирует истины вне времени: законы, обобщения, канон. Эта форма широко используется в священных текстах и научных формулировках.

5.3 Порядок суффиксов

Глагольная форма строится по схеме:

Основа + время + число + эвиденциальность

Пример: khal-en-ak-ven = «делает (множество, я вижу)». Порядок суффиксов фиксирован и обязателен.

5.4 Вид и залог

Помимо времени, глагол может выражать:

  • Вид — совершенный/несовершенный (суффикс -thal для результативности);
  • Залог — актив/пассив (пассив -vex-thar);
  • Каузатив — суффикс -khal-ven.

Эти категории факультативны и присоединяются между основой и временным суффиксом.

5.5 Пример

Xha'ruun-sha the-thar khal-en-ven
Народ-ERG почва-ACC делать-NPST-ПРЯМ
«Народ обрабатывает почву (я вижу это)»

Итоги главы

  1. Спряжение по времени (4), числу (3), эвиденциальности (4 — обязательно).
  2. Вневременное время (-el) — для истин вне времени.
  3. Порядок суффиксов: основа + время + число + эвиденциальность.
  4. Вид, залог, каузатив — факультативные категории.
  5. Эвиденциальность обязательна в каждой глагольной форме.
