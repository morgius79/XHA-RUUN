Том IV: Язык — Глава 8: Лексикон и словообразование

«Каждый корень — это семя. Добавь суффикс — и вырастет новое слово. 500 базовых корней порождают 50 000 слов.» — Лексикология Xha'Ruun, Академия

Связанные разделы: → см. [Том IV, Гл.03–07], → см. [Том I, Гл.06, «Язык и письменность»] Объём: 25 страниц

Введение

Лексическая система Xha'Ruun построена на компактной корневой базе: ~500 базовых корней порождают десятки тысяч производных слов. Корень — односложный (CVC или CV); словообразование — агглютинативное, через суффиксы с прозрачной семантикой.

8.1 Корневая система

Язык Xha'Ruun базируется на ~500 корнях. Каждый корень — односложный (CVC или CV).

Корень Значение Производные
xha- мысль, разум xha'ruun (народ), xha'ven (истина)
khar- свет, звезда khar'vex (светило), kharan (световой)
the- почва thexar (планета), theri (почва)
sha- язык, слово sharuu (письменность), shaven (диалект)
ruun- народ ruuna (община), ruunen (общество)

Корни реестрированы (L-000001–L-000500) и служат основой лексикографии. Полисемия корней — источник словообразовательной продуктивности.

8.2 Словообразование

Способ Суффикс Пример
Существительное -∅ khal (жизнь)
Прилагательное -an kharan (световой)
Глагол -en khalen (жить)
Абстракция -ven khalven (жизненность)
Деятель -sha khalsha (живущий)
Место -the khalthе (среда обитания)

Каждый суффикс имеет одно значение — агглютинативный принцип сохраняется и в словообразовании. Комбинации суффиксов создают многосложные производные с прозрачной внутренней формой.

8.3 Сложные слова

Композиция — второй источник пополнения лексики:

  • xha + ruun → xha'ruun (народ — букв. «разум + народ»);
  • khar + vex → khar'vex (звезда — «свет + дом»);
  • the + xar → thexar (планета — «почва + родина»).

Апостроф маркирует границу компонентов сложного слова.

8.4 Семантические поля

Корни группируются в семантические поля:

  • Природа — khar (свет), the (почва), mor (время), ven (истина);
  • Общество — sha (язык), ruun (народ), khal (жизнь), rass (согласие);
  • Действие — khalen (жить), vexen (строить), tharen (говорить).

Поля отражают культурные приоритеты цивилизации (→ см. [Том I, Гл.06]).

8.5 Заимствования

Словарь включает ограниченные заимствования из языков других видов:

  • Kel'vash — горные и технические термины;
  • Moryn — океанографические термины.

Заимствования фонологически адаптируются (→ см. [Том IV, Гл.02, «Фонология»]).

Итоги главы

  1. ~500 корней (CVC/CV) порождают 50 000+ слов.
  2. Словообразование агглютинативное, суффиксы однозначны.
  3. Композиция — второй источник лексики.
  4. Семантические поля отражают культурные приоритеты.
  5. Ограниченные заимствования из языков Kel'vash и Moryn.
