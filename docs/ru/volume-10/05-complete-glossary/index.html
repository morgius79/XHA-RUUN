Том X: Приложения — Глава 5: Полный глоссарий

Связанные разделы: → см. [Том IX, «Словарь»], → см. [Том IV, Гл.08, «Лексикон»]

Структура записи

Каждая запись глоссария следует формату:

термин (источник) — определение. → см. [Том, Глава]

A–E

Ablative (лингв.) — падеж движения от источника (-tor). → см. [Том IV, Гл.04]

Adit (горн.) — горизонтальная выработка; məlkhar в Xha'Ruun, заимствование из Kel'vash. → см. [Том IX, Гл.09]

Agglutination (лингв.) — словообразование через суффиксы, сохраняющие форму и значение. → см. [Том IV, Гл.03]

Allative (лингв.) — падеж движения к цели (-khar). → см. [Том IV, Гл.04]

Anthroponym (лингв.) — личное имя; в Xha'Ruun: два корня через дефис. → см. [Том IX, Гл.08]

Базовые корни — 16 корней Xha'Ruun (xa, xha, ruun, khar, the, sha, ven, mor, rass, thar, khal, tor, vex, el, en, sha), из которых порождается вся лексика. → см. [Том IX, Гл.02]

Bioluminescence (биол.) — свечение живых организмов; основа языка Moryn. → см. [Том VII, Гл.07]

Carbon-water life — биохимия Xha'ruun и большинства Théxar-форм. → см. [Том I, Гл.11]

Case (лингв.) — грамматическая категория, 14 падежей в Xha'Ruun. → см. [Том IV, Гл.04]

Chemoautotrophy (биол.) — метаболизм Kel'vash, получение энергии из неорганических реакций. → см. [Том VII, Гл.06]

Comitative (лингв.) — падеж совместности (-rass). → см. [Том IV, Гл.04]

Cosmonym (лингв.) — название космического объекта (Khar'Vex, Théxar). → см. [Том IX, Гл.08]

Council of Unity — Rass-Vokh-Sha, высший орган власти (49 членов). → см. [Том III, Гл.02]

Dative (лингв.) — падеж адресата (-ven). → см. [Том IV, Гл.04]

Deep Lexicon — «Глубинный словарь», свод заимствований из Moryn, +2 400 г. → см. [Том IX, Гл.10]

Domain — Домен, административно-территориальная единица; всего 8. → см. [Том III, Гл.05]

Dual (лингв.) — двойственное число (-sha), обязательно для парных объектов. → см. [Том IV, Гл.03]

Эвиденциальность — обязательная грамматическая категория: источник знания (-ven, -sha, -tor, -rass). → см. [Том IV, Гл.06]

F–K

Evidential (лингв.) — см. Эвиденциальность.

Executive Committee — Исполнительный комитет, 12 членов Совета Единства. → см. [Том III, Гл.02]

Fusion energy — термоядерная энергетика, основной источник с +1 200 г. → см. [Том VI, Гл.01]

Genitive (лингв.) — падеж принадлежности (-mor). → см. [Том IV, Гл.04]

Gharra — Южный океан (87.5 млн км²), место обитания Moryn. → см. [Том I, Гл.13]

Guild — Гильдия, профессиональное объединение; всего 12. → см. [Том III, Гл.04]

Helium-3 — He-3, основное топливо термоядерных реакторов, добыча с Thel. → см. [Том VI, Гл.01]

Inessive (лингв.) — падеж местонахождения в (-the). → см. [Том IV, Гл.04]

Instrumental (лингв.) — падеж орудия (-khal). → см. [Том IV, Гл.04]

K3V — спектральный класс Khar'Vex, оранжевый карлик. → см. [Том I, Гл.02]

Kel'vash — кремний-органический разумный вид высокогорий. → см. [Том VII, Гл.06]

Khar'Vex — родная звезда (класс K3V, 0.74 M☉). → см. [Том I, Гл.02]

Kharak — северный континент (34.2 млн км²). → см. [Том I, Гл.13]

Kharak-Thar — Домен Свет-Река, административный центр. → см. [Том VIII, Гл.09]

L–P

Lexeme — лексема; полная парадигма слова. → см. [Том IX]

Loanword — заимствование; 31 из Kel'vash, 26 из Moryn. → см. [Том IX, Гл.09, Гл.10]

Maglev — thelmorar, магнитная левитация, основной наземный транспорт. → см. [Том VI, Гл.02]

Moryn — углерод-водный разумный вид океанских глубин. → см. [Том VII, Гл.07]

Mormor — год Théxar (412.7 земных суток, 14 месяцев). → см. [Том I, Гл.34]

Nominative (лингв.) — падеж подлежащего (-∅). → см. [Том IV, Гл.04]

Orbital elevator — khar-tormor, орбитальный лифт, введён +3 000 г. → см. [Том VI, Гл.02]

Pantheon — Семь Голосов (Khar-Vex, Thar-Mor, The-Xa, Ven-Ash, Rass-Ul, Ghal-Thar, Nur-Vek). → см. [Том V, «Мифология»]

Phonotactics (лингв.) — правила организации звуков в слоги. → см. [Том IV, Гл.02]

Proper name — см. Anthroponym, Cosmonym, Toponym.

Q–T

Rass-Vokh-Sha — см. Council of Unity.

Reactor — tharkhal, термоядерный реактор. → см. [Том VI, Гл.01]

Rhuval — центральный континент (21.7 млн км²). → см. [Том I, Гл.13]

Root — корень слова; Xha'Ruun имеет ~500 корней. → см. [Том IX, Гл.02]

Senary — шестеричная система счисления, основа математики Xha'Ruun. → см. [Том IV, Гл.09]

Serrin — большой спутник (425 км, 31.4 суток). → см. [Том I, Гл.24]

Seven Voices — см. Pantheon.

Sharuu — слоговая письменность Xha'Ruun (326 знаков). → см. [Том IV, Гл.07]

Silicon-acid life — биохимия Kel'vash (кремний + H₂SO₄). → см. [Том VII, Гл.06]

SOV — порядок слов Subject-Object-Verb. → см. [Том IV, Гл.03]

Superessive (лингв.) — падеж местонахождения на (-vex). → см. [Том IV, Гл.04]

Thel — малый спутник (178 км, 78.2 суток, захваченный астероид). → см. [Том I, Гл.24]

Théxar — родная планета (0.88 M⊕, 0.93 R⊕). → см. [Том I, Гл.03]

Thermochromadae — класс организмов с шестибуквенной ДНК. → см. [Том I, Гл.11]

Toponym (лингв.) — географическое название (Kharak, Gharra). → см. [Том IX, Гл.08]

Translative (лингв.) — падеж превращения в (-el). → см. [Том IV, Гл.04]

U–Z

Unity — Rass, центральное понятие политической философии. → см. [Том III, Гл.01]

Vexar — южный континент (18.5 млн км²). → см. [Том I, Гл.13]

Vowel harmony (лингв.) — гармония гласных по ряду. → см. [Том IV, Гл.02]

X-Y pair — дополнительная пара оснований ДНК, уникальная для Théxar. → см. [Том I, Гл.11]

Xha'Ruun — самоназвание вида и языка; буквально «разум-народ». → см. [Том I, Гл.05]

Xharuun — альтернативная латинская транскрипция (без апострофа). → см. [Том IV, Гл.01]
