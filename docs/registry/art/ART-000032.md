# ART-000032: Серный цикл Théxar

**Тип:** схема (растровая, PNG, AI-генерация)
**Статус:** pending (ожидает генерации)
**Создан:** 2026-08-07

## Описание

Биогеохимическая схема серного цикла — уникального для Théxar (H₂S как энергетический субстрат, а не отход): атмосфера (H₂S 0.0008%, биомаркер планеты) ↔ наземная биосфера + почвы (хемосинтез 52 млн ру S/цикл) → океан (хемосинтез 340 млн ру S/цикл) → литосфера (FeS₂, CaSO₄), с возвратом через вулканизм.

Потоки (млн ру S/цикл): биогенная эмиссия 46, осаждение 48, речной сток 121, вулканический H₂S с дна 84, захоронение пирита 118, вулканизм 72.

Палитра отличается от ART-000031 (индиго вместо бирюзового), чтобы визуально различать циклы.

Заменяет ASCII-схему в Гл.13 Тома VII (RU+EN).
