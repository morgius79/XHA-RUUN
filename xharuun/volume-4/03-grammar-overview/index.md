## Введение

Грамматика языка Xha'Ruun — агглютинативная система высокой точности. Каждая грамматическая категория выражается отдельной морфемой, что исключает двусмысленность: падеж, число, время и очевидность маркируются явно. Обзор даёт типологическую характеристику и структуру слова.

---

## 3.1 Типологические характеристики

| Параметр | Значение |
|----------|----------|
| Тип | Агглютинативная, суффиксальная |
| Порядок слов | SOV (субъект-объект-глагол) |
| Падежи | 14 |
| Числа | 3 (единственное, двойственное, множественное) |
| Род | Отсутствует |
| Эвиденциальность | Обязательная (4 типа) |
| Время | 3 + 1 (прошлое, наст., будущее + вневременное) |

Агглютинация — доминирующий способ словоизменения: морфемы присоединяются последовательно, без фузии. Отсутствие рода упрощает согласование; тройственное число отражает трёхполую биологию говорящих.

---

## 3.2 Структура слова

```
Основа-(корень) + суффикс_числа + суффикс_падежа + (эвиденциальность)
```

Пример: **xha'ruun-ak-sha-ven** → «народ-МН-ЭРГ-ПРЯМ» = «народы (я вижу, что они)»

Порядок суффиксов фиксирован: число → падеж → эвиденциальность. Морфемы сегментируемы: каждая несёт одно значение, что делает слово прозрачным для анализа.

---

## 3.3 Падежная система

14 падежей делятся на группы (→ см. [Том IV, Гл.04, «Падежи»]):

- **Грамматические**: номинатив, эргатив, аккузатив, генитив;
- **Пространственные**: локатив, аблатив, аллатив, пролатив;
- **Временные**: темпораль, пролатив времени;
- **Прочие**: инструменталь, комитатив, бенефактив, транслатив.

---

## 3.4 Эвиденциальность

Обязательная категория — говорящий обязан указать источник информации (→ см. [Том IV, Гл.06, «Эвиденциальность»]):

- Прямая (видел/слышал);
- Инференциальная (вывод);
- Пересказывательная (с чужих слов);
- Цитативная (прямая речь).

---

## 3.5 Синтаксис

Порядок SOV дополняется:

- **Агглютинативными послелогами** (падежные суффиксы выполняют их роль);
- **Свободным порядком в пределах клаузы** при маркированных падежах;
- **Сложным предложением** через суффиксальные союзы и эвиденциальность.

---

## Итоги главы

1. Агглютинативная суффиксальная система, порядок SOV.
2. 14 падежей, 3 числа, отсутствие рода.
3. Обязательная эвиденциальность (4 типа).
4. Структура слова: основа + число + падеж + эвиденциальность.
5. Морфемы сегментируемы — слово прозрачно для анализа.
