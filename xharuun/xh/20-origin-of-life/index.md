## 20.2 Abiogenesis Site — Gharra Hydrothermal Vent

**Three gradients met:**

1. **T gradient:** vent 235.4°X → surround 47.3°X
2. **pH gradient:** vent acidic 4–5 → ocean 6.5
3. **Catalytic surfaces:** pyrite FeS₂, clay, Si sediments
4. **Energy:** chemical (H₂S, H₂, CH₄) + thermal

```
H₂S + H₂ + CH₄ + CO₂
     ↓
FeS₂ catalytic surface
     ↓
Prebiotic organics → 6-letter RNA
```

> **Rass-Ven:** 6-letter code = direct radiation-response. Lab: 4-letter RNA degrades 5× faster under UV. Early Théxar UV 3.5× → 6-letter decisive advantage.

## 20.3 6-Letter Code Hypothesis

**Radiation Protection Hypothesis:**

| Step | Mechanism | Result |
|------|-----------|--------|
| 1 | High UV → frequent mutation in 4-letter RNA | Instability |
| 2 | Added bases: P (pyrimidine-N), X (xanthosine) | Chain stability + redundancy |
| 3 | 6³ = 216 codons (vs 4³ = 64) | 24 amino acids, ~9× redundancy, 5× mutation resistance |

## 20.5 Oxygen Catastrophe (4.0–3.8 bln)

> **Rass-Ven:** O₂ catastrophe **1.6 bln earlier** (4.0 vs 2.4) — earlier chromophyll. More gradual: O₂ accumulated over ~600 M (not 200 M) → anaerobes adapted.

**Consequences:**
1. Anaerobic mass extinction (refugia: deep-water, underground)
2. Fe²⁺ oxidation → Banded Iron Formations (BIF)
3. Ozone layer formation
