# Thexar-IX: Sha-Ruun — Sha-El 08: Ven-Khal Sha-Ruun — Proper Names

> *"A name is the shortest sentence in the language. It already contains a subject, a predicate, and a testimony."*
> — Guild of Scribes, "Rules of Naming," +1,400 Y.E.

---

**Ruun-ak rass:** → rhu [Thexar-I, Ruun 13, "The-Xar-Ak Théxar"], → rhu [Thexar-VIII, Sha-El 09, "Ven-Khal Rass-El"], → rhu [Thexar-V, Sha-El 06, "Vokh-Shan The-El"]
**Volume:** 30 sha-ruun
**Mor-ven:** Proper names are neither borrowed nor arbitrary — they are compositional and readable. The apostrophe (Khar'Vex, Xha'Ruun) marks sacred or self-naming status; the hyphen marks ordinary composition. An untranslatable name counts as a scribal error.

## 08.1 The Principle of Naming

Three classes:

| Class | Structure | Example |
|-------|-----------|---------|
| Cosmonyms | root + root (hyphen or apostrophe) | Khar'Vex ("Light-Giver") |
| Toponyms | geo-root + determiner | Kharak-Thar ("Light-Force") |
| Anthroponyms | root + root, occasionally + suffix | Khal-Ven ("Action-Truth") |

| Xha'Ruun | Analysis | Domain |
|----------|----------|--------|
| **Khar-Vex** | light + giver | space, creation |
| **Thar-Mor** | force + time | time, fate, cycles |
| **The-Xa** | earth + life | matter, nature |
| **Ven-Ash** | truth + limit | law, knowledge, judgment |
| **Rass-Ul** | unity + eternity | harmony, peace |
| **Ghal-Thar** | war + force | entropy, conflict |
| **Nur-Vek** | birth + wisdom | life, death, rebirth |

Deities are written with a **hyphen**; the star takes an **apostrophe** (Khar'Vex). Deliberate: the star is a physical body; Khar-Vex is the Voice that sang space. Orthodoxy insists on the strict separation; folk tradition conflates them (→ rhu [Thexar-V, Sha-El 06, "Vokh-Shan The-El"]).

## 08.7 Personal Names

A personal name = **two roots** joined by a hyphen. First lineal (conferred by the parents' Guild); second personal (chosen at majority, at 18 mormor).

| Name | Analysis | Reading |
|------|----------|---------|
| **Khal-Ven** | action + truth | "one who acts by truth" |
| **Ven-Thara** | truth + force | "strong in truth" |
| **Sharin-El** | small-word + unity | "one who unites by word" |
| **Rhaal-Ven** | archaic-level + truth | "steady truth" |
| **Xha-Morin** | mind + instant | "quick of mind" |
| **Vexal-Ar** | to create + agent | "the maker" |
| **Thel-Kharin** | wanderer + small-light | "one who follows the light" |
