## Introduction

The grammar of the Xha'Ruun language is an agglutinative system of high precision. Each grammatical category is expressed by a separate morpheme, which eliminates ambiguity: case, number, tense, and evidentiality are marked explicitly. The overview gives a typological characterization and the structure of the word.

---

## 3.1 Typological Characteristics

| Parameter | Value |
|-----------|-------|
| Type | Agglutinative, suffixal |
| Word order | SOV (subject-object-verb) |
| Cases | 14 |
| Numbers | 3 (singular, dual, plural) |
| Gender | None |
| Evidentiality | Mandatory (4 types) |
| Tense | 3 + 1 (past, present, future + gnomic) |

Agglutination is the dominant mode of inflection: morphemes are attached sequentially, without fusion. The absence of gender simplifies agreement; the triple number reflects the three-sex biology of the speakers.

---

## 3.2 Word Structure

```
Stem-(root) + number_suffix + case_suffix + (evidentiality)
```

Example: **xha'ruun-ak-sha-ven** → "people-PL-ERG-DIR" = "the peoples (I see that they)"

The order of suffixes is fixed: number → case → evidentiality. Morphemes are segmentable: each carries one meaning, which makes the word transparent for analysis.

---

## 3.3 Case System

The 14 cases are divided into groups (→ see [Volume IV, Ch.04, "14 Cases"]):

- **Grammatical**: nominative, ergative, accusative, genitive;
- **Spatial**: locative, ablative, allative, prolative;
- **Temporal**: temporal, prolative of time;
- **Other**: instrumental, comitative, benefactive, translative.

---

## 3.4 Evidentiality

A mandatory category — the speaker is obliged to indicate the source of information (→ see [Volume IV, Ch.06, "Evidentiality"]):

- Direct (saw/heard);
- Inferential (conclusion);
- Reportative (from others' words);
- Quotative (direct speech).

---

## 3.5 Syntax

The SOV order is supplemented by:

- **Agglutinative postpositions** (case suffixes perform their role);
- **Free order within the clause** with marked cases;
- **Complex sentences** through suffixal conjunctions and evidentiality.
