## A–E

**Ablative** (*ling.*) — case of motion from a source (-tor). → see [Volume IV, Ch.04]

**Allative** (*ling.*) — case of motion toward a goal (-khar). → see [Volume IV, Ch.04]

**Bioluminescence** (*biol.*) — light emission by living organisms; the basis of Moryn language. → see [Volume VII, Ch.07]

**Carbon-water life** — the biochemistry of the Xha'ruun and most Théxar lifeforms. → see [Volume I, Ch.11]

**Case** (*ling.*) — grammatical category; 14 cases in Xha'Ruun. → see [Volume IV, Ch.04]

**Chemoautotrophy** (*biol.*) — Kel'vash metabolism, obtaining energy from inorganic reactions. → see [Volume VII, Ch.06]

**Comitative** (*ling.*) — case of accompaniment (-rass). → see [Volume IV, Ch.04]

**Cosmonym** (*ling.*) — name of a celestial object (Khar'Vex, Théxar). → see [Volume IX, Ch.08]

**Council of Unity** — **Rass-Vokh-Sha**, the supreme governing body (49 members). → see [Volume III, Ch.02]

**Dative** (*ling.*) — case of the recipient (-ven). → see [Volume IV, Ch.04]

**Deep Lexicon** — compendium of Moryn loans, +2,400 Y.E. → see [Volume IX, Ch.10]

**Domain** — administrative-territorial unit; 8 in total. → see [Volume III, Ch.05]

**Dual** (*ling.*) — dual number (-sha), obligatory for paired objects. → see [Volume IV, Ch.03]

**Evidentiality** — obligatory grammatical category: source of knowledge (-ven, -sha, -tor, -rass). → see [Volume IV, Ch.06]
